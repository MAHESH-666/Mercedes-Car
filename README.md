# Mercedes-Benz Concept Landing Page

A static vehicle-themed landing-page design inspired by a premium car website. It uses HTML, CSS, Bootstrap, imagery, and JavaScript interactions to display model navigation and vehicle-style highlights.

## Features

- Single-page vehicle landing layout
- Model navigation links and interactive page elements
- Hero imagery and performance-style highlights
- Custom CSS styling with Bootstrap support

## Technology

- HTML5
- CSS3
- JavaScript
- Bootstrap 5 (CDN)
- Local image assets in `images/`

## Run locally

Open `index.html` in a modern browser. Keep the `images/` directory and `style.css` in their current relative locations.

## Scope

This is a front-end learning/demo design, not an official Mercedes-Benz website. It has no real vehicle ordering, inventory, authentication, or payment backend. Brand assets and specifications should be verified before public commercial use.
